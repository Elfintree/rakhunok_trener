# Рахунок-тренер

Telegram Mini App для тренування усного рахунку: 10 прикладів за раунд,
введення з великої цифрової клавіатури, помилкові приклади повертаються
наприкінці раунду й потрапляють у «Роботу над помилками».

Рівні: додавання/віднімання до 20, через десяток, впереміш, пропущене число,
подвоєння (через 2, через 5, до 100), половина.

- Один файл `index.html`, без сервера й збірки; хостинг — GitHub Pages.
- Прогрес — Telegram CloudStorage (той самий на всіх пристроях),
  поза Telegram — localStorage.
- Бот лише відкриває сторінку кнопкою меню (налаштовано в @BotFather),
  токен ніде не використовується.

Локально: `python -m http.server` і відкрити http://127.0.0.1:8000/
